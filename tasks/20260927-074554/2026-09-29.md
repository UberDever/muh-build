## Idea: parallel builds (user: not wanted now, good to keep possible)
- (agent) Fits the design: MuhNinja's target graph gives a ready set; the snapshot is read-only during a project build and only `built` changes, as jobs finish.
- (agent) Stock Lua can run N processes at once through `io.popen`: it starts the process at once and blocks only on read or close; `close` returns the exit status (POSIX and Windows `_popen`). Limits: closing in start order means a slow first job delays the pool; stderr interleaves unless each job writes to its own file.
- (agent) Interface cost: one host function, e.g. `host.spawn(cmd) -> handle`, `handle:wait() -> ok`; the mock can run immediately. Recipes stay sequential; building independent dependencies together would be an explicit recipe call.
